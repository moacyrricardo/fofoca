Numbered pins

  • 1 Current-setup banner stays above the tabs and follows the choices (e.g. "Swap layout · Balanced updates").
  • 2 Tabs, same style as the meeting page: Processing (default) · Models · Calendars · Storage. The old "files" card moved into Storage.
  • 3 Processing says which models it is planning for, with a link to Models — the fit meter and the disabled "doesn't fit" card depend on them.
  • 4 During the call: live transcript and/or live summary.
  • 5 If both are on: where each runs (four layouts; "both resident" shown disabled with why).
  • 6 Live updates: Fast / Balanced / Light — one setting instead of piece length + summary cadence. Raw values stay in config.toml; editing them there would show "Custom" (not drawn).
  • 6b After the call: speakers, checked notes and where notes run.
  • 7 Models tab: model per task, engines, downloads — nothing bundled.

Invented (not in the product yet)

  • The whole Models & workflow section, model pickers, download flow, layout cards with GPU/CPU lane diagrams, the GPU-memory fit meter, the "Suggested for this computer" badge (would come from spec 002's probe + benchmark), the "applies to the next recording" lock.
  • Live updates presets; only Balanced is measured (12.7 s median, spec 010) — Fast/Light are marked "estimate".
  • "Record only, transcribe after the call" (both live toggles off) is a new mode — today live transcription is always on.

Numbers

  • Measured (benchmarks-mx230): turbo 824 MiB VRAM; Qwen3.5-2B 1,414 MiB @8K; swap ~3 s; Qwen ~17 tok/s GPU, 11–13 tok/s CPU.
  • Guessed: file sizes in the download menu are approximate; the "slower / may fall behind" wording for CPU transcription is qualitative (CPU whisper speed on this machine should be re-measured); small-model VRAM (~400 MiB) is an estimate.

Calendars

fo-foca reads upcoming meetings to name recordings and show what's next. Read-only.

  1. Open Google Calendar on the web → ⚙ Settings.
  2. Under Settings for my calendars, pick the calendar → Integrate calendar.
  3. Copy Secret address in iCal format and paste it below.

Outlook, iCloud and Fastmail have the same kind of link. You can also paste the path of a local .ics file. Anyone with the link can read the calendar — if it leaks, reset it in Google and add the new one here.
